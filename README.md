# Widgets

A separate home for small, self-contained interactive components, kept out of the Games and library shelves.

One component set:

| # | Set | What it is | Source |
|---|---|---|---|
| 01 | [Sakuga VFX](./sakuga-vfx/) | Twelve ordinary UI controls that react like anime: springs, squash, smoke bursts, slashes and manga sound-effect lettering. One file each, no dependencies. | [finktheartist/sakuga-vfx](https://github.com/finktheartist/sakuga-vfx) · [own fork](https://github.com/bear20252026/sakuga-vfx) |

The root page is a one-card gallery. `sakuga-vfx/` is a complete static mirror: `gallery/` is the live demo with all twelve controls, and the twelve component folders plus `core.js`, `registry.json` and `llms.txt` are intact. Each component is a single file, so it can be copied into another project without a build step.

Live: <https://bear20252026.github.io/widgets/>

## Sakuga VFX upstream

The original live gallery is [sakuga-vfx.vercel.app](https://sakuga-vfx.vercel.app), with source at [finktheartist/sakuga-vfx](https://github.com/finktheartist/sakuga-vfx). The local copy is the static gallery from the public fork; all code and artwork remain under the original MIT licence, which is kept in `sakuga-vfx/LICENSE`.
